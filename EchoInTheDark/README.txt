==========================================================
 暗夜回声 · Echo in the Dark
 完整游戏文件夹 —— 使用与打包说明
==========================================================

【这是什么】
一款纯 HTML5 Canvas 的极简潜行解谜游戏，零外部资源依赖：
画面、声呐射线、守卫 AI、程序化音效全部由代码生成，
不依赖任何图片、音频、字体文件，也不联网。

你身处完全黑暗的地下迷宫。用声呐照亮墙体，在
"看见"与"被听见"之间求生，躲开守卫，抵达绿色出口。

【当前状态】
✅ 已打包完成。可直接发送给别人的单文件：
   dist\EchoInTheDark_win64.exe  （约 71 MB，双击即玩）
   对方无需安装任何东西；如遇 SmartScreen 提示，选
   "更多信息 → 仍要运行" 即可（未签名，属正常现象）。

----------------------------------------------------------
【直接游玩（无需打包，任选其一）】

方式一：浏览器直接打开
  双击 src\index.html 即可游玩。
  （Windows 下也可用任意现代浏览器打开）

方式二：本地运行（需已安装 Node.js）
  在 EchoInTheDark 文件夹内执行：
      npm install
      npm start
  会弹出一个桌面窗口运行游戏。

----------------------------------------------------------
【操作说明】

  移动 ............ W A S D 或 方向键
  声呐（蓄力） .... 按住 空格 或 鼠标左键，松开释放
  诱饵石子 ........ 鼠标右键 或 E（每关 3 颗）
  重开本关 ........ R
  关卡编辑器 ...... Tab
  开始游戏 ........ 点击开始 / 回车

  玩法要点：
  - 声呐会照亮墙体轮廓，但同时产生噪音，越远越容易被听见。
  - 蓄力越久，声呐半径越大、噪音越大。
  - 诱饵石子会发出声响，可把守卫引到别处。
  - 守卫分巡逻 / 警戒 / 搜索三种状态，看见你或听见你都会追来。

----------------------------------------------------------
【打包成单文件 .exe 发给别人】

前提：本机已安装 Node.js（https://nodejs.org，选 LTS 版本）。

在 EchoInTheDark 文件夹内执行：

    npm install
    npm run dist

完成后，在 dist\ 文件夹内会生成：

    EchoInTheDark_win64.exe   （单文件便携版，可直接双击运行）

把这个 .exe 单独发给别人即可，对方无需安装任何东西。

（如需解包版文件夹，可执行： npm run dist:dir）

----------------------------------------------------------
【常见问题】

Q: 对方打开 exe 时系统提示"未知发布者"？
A: 这是正常现象。因为 exe 未购买代码签名证书，Windows
   SmartScreen 会提示。点"更多信息"→"仍要运行"即可。
   游戏本身无恶意代码、不联网。

Q: 双击后没有声音？
A: 浏览器/系统需允许页面自动播放音频。首次点击"开始游戏"
   后才会初始化音频（浏览器安全策略要求用户先交互）。

Q: 想改关卡？
A: 游戏内按 Tab 打开关卡编辑器，可画墙、设守卫巡逻点、
   改出口和出生点；也可"导出 JSON"备份，"导入并应用"加载。

Q: 想改成全屏 / 调整窗口大小？
A: 游戏画面会自动缩放适配窗口，窗口可自由拖动大小。
   （在 main.js 中可改 width/height 初始尺寸）
