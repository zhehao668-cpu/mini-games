# mini-games

个人小游戏合集。

## 游戏列表

| 游戏 | 说明 | 目录 |
|------|------|------|
| 暗夜回声 · Echo in the Dark | HTML5 Canvas 极简潜行解谜：声呐照亮墙体、躲避守卫、抵达出口 | [`EchoInTheDark/`](EchoInTheDark/) |

## 如何运行

每个游戏目录里都有对应的说明（`README.txt` / `README.md`）。

《暗夜回声》可用浏览器直接打开 `EchoInTheDark/src/index.html` 游玩；也可在其目录内执行 `npm install && npm start` 用 Electron 桌面窗口运行。打包好的 Windows 可执行文件见本仓库的 [Releases](https://github.com/zhehao668-cpu/mini-games/releases)。
